# Migrating to the Codex-owned field contract

This note covers the removal of the FormSet module dependency.

## Declarations

- Construct `schema.RecordType`, `schema.Field`, and `schema.Relation` in this module.
- Do not import `github.com/fastygo/formset` to declare a Codex manifest.
- JSON names on `record` are unchanged: `id`, `label`, `scope`, `fields`, `relations`.

## Validation codes

- `schema.resource.formset_invalid` is now `schema.resource.record_invalid`.
- `schema.manifest.formset_invalid` is replaced by relation and resource codes from Codex validation.
- `schema.entry.formset_invalid` is now `schema.entry.field_invalid`.

Branch on `validation.Code` and `validation.Path`.
