# Migrating from v0.1.0 to v0.2.0

`v0.2.0` is a deliberate pre-v1 contract correction.

## Resource declaration

- Replace embedded `RecordType` fields with `Resource.Record`.
- Remove `Resource.Collection`; route names belong to the delivery adapter.
- Remove `Resource.Public`; use FormSet `Record.Visibility` only for
  resource-level visibility semantics.
- Replace `CoreResources` and `WithCoreResources` with explicit resources in
  the application manifest.

## Fields and entries

- Add namespaced Codex rules for GoBackend-specific scalar semantics.
- Declare each relation once in `Record.Relations`, with a relation field that
  has the same ID.
- Store localized declared fields in `Entry.Locales[locale].Data`.
- Store all other declared fields in `Entry.Metadata`.
- Call `Resource.ValidateEntry` at adapter boundaries.
- Use `Resource.PublicProjection` when FormSet sensitivity must be applied.

## Identity and errors

- Use `Manifest.Digest` for versioned canonical manifest identity.
- Branch on `validation.Code` and `validation.Path`, never on human error
  strings.

The JSON resource shape changes from `"record_type"` to `"record"` and removes
`"collection"` and `"public"`. Consumers must update fixtures before changing
their version pin.
